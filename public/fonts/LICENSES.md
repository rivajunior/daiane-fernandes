# Font licenses

Both fonts are licensed under the SIL Open Font License 1.1 and self-hosted here.
Files are the Latin subsets (Basic Latin, Latin-1 accents and common punctuation, enough for pt-BR) of the variable `wght` builds distributed by Fontsource, further limited to the 400–500 weight range with fonttools (`varLib.instancer` + `pyftsubset`).

| File                               | Font                | Role                                         | Source                                |
| ---------------------------------- | ------------------- | -------------------------------------------- | ------------------------------------- |
| `fraunces-latin-wght-normal.woff2` | Fraunces (variable) | Headings (look-alike for Chan Romance)       | https://fontsource.org/fonts/fraunces |
| `jost-latin-wght-normal.woff2`     | Jost (variable)     | Body (look-alike for ITC Avant Garde Gothic) | https://fontsource.org/fonts/jost     |

License texts: `LICENSE-fraunces.txt`, `LICENSE-jost.txt`.
